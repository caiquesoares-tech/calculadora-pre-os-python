# 💰 Calculadora de Reajuste e Tributação Modularizada

Este script foi desenvolvido para automatizar o processo de atualização de preços de produtos, aplicando margens de aumento e cálculos de taxas sobre o valor final.

### 🎯 Objetivo do Projeto
O foco principal deste exercício foi aplicar o conceito de **Modularização** em Python. O sistema é dividido em funções com responsabilidades únicas, o que facilita a manutenção e a reutilização do código.

### 🛠️ Especificações Técnicas
* **Reajuste de Preço**: Aplica um aumento fixo de **10%** (fator 1.10) sobre o valor original.
* **Cálculo de Taxa**: Calcula uma alíquota de **2,5%** (fator 0.025) sobre o valor já reajustado.
* **Formatação**: Saída de dados configurada para duas casas decimais (`:.2f`).

### 🚀 Tecnologias
* Python 3
* Lógica de Programação e Modularização
